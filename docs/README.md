# Kids Thinking Lab — Product & Engineering Documentation

GitHub là nguồn chính thức cho thiết kế, yêu cầu và quyết định triển khai. ChatGPT Project hỗ trợ thảo luận; mọi quyết định được chốt phải cập nhật vào repo.

## Cấu trúc
- `00-project/`: vision, scope, architecture, roadmap
- `01-epics/`: tài liệu độc lập theo từng Epic
- `02-architecture/`: thiết kế hệ thống, dữ liệu, ADR
- `03-standards/`: tiêu chuẩn phát triển và Definition of Done
- `04-templates/`: mẫu Epic, Feature, Backlog

## Quy ước
- Epic ID cố định `EP-XX`; Feature `FT-XXX`; Story `US-XXX`.
- Mỗi Epic có `README.md`, `context.md`, `requirements.md`, `design.md`, `backlog.md`, `decisions.md`.
- GitHub Issues/Projects quản lý trạng thái thực thi; file backlog ghi phạm vi và liên kết.
- Epic đầu tiên để phát triển gameplay: **EP-01 Cán cân thăng bằng**. EP-00 là hạ tầng hỗ trợ.
