# Design — Học tập thích ứng

## Approach
Mastery theo kỹ năng, lựa chọn bài và ôn tập; không chỉ dựa vào tốc độ.

## Components
- Skill graph
- Mastery score
- Adaptive selection
- Retention

## Data contract
Schema có version, validator độc lập UI, hỗ trợ unit tests.

## Open questions
Chốt UI và chi tiết dữ liệu trong Feature Spec trước khi code.
