# EP-01 — Cán cân thăng bằng

Status: MVP implementation

Audience: children ages 5–7.

## Goals
- Understand heavier, lighter, equal.
- Reason about missing weights.
- Explain answer before submitting.

## MVP
Five map levels; illustrated balance scale; picture-like choices; Vietnamese speech synthesis; explanation prompt; submit and feedback; browser progress.

## Future
12 levels, drag and drop, audio recording, parent dashboard, database.
