# Design — Cán cân thăng bằng

## Approach
Map 12 chặng, câu hỏi hình cán cân, đáp án hình, TTS nghe lại, yêu cầu giải thích trước submit, feedback.

## Components
- Map progression
- Scale illustration
- Picture answers
- Narration replay
- Explanation gate
- Validation and feedback
- Progress tracking

## Data contract
Schema có version, validator độc lập UI, hỗ trợ unit tests.

## Open questions
Chốt UI và chi tiết dữ liệu trong Feature Spec trước khi code.
