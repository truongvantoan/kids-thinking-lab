# Design — Challenge Engine

## Approach
Schema câu hỏi, bộ kiểm tra đáp án, render và giải thích tách biệt UI.

## Components
- Challenge schema
- Validator
- Renderer registry
- Content versioning

## Data contract
Schema có version, validator độc lập UI, hỗ trợ unit tests.

## Open questions
Chốt UI và chi tiết dữ liệu trong Feature Spec trước khi code.
