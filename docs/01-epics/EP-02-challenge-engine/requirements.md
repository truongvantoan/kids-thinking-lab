# Requirements — Challenge Engine

## Objective
Schema câu hỏi, bộ kiểm tra đáp án, render và giải thích tách biệt UI.

## Functional requirements
- FR-1: Challenge schema
- FR-2: Validator
- FR-3: Renderer registry
- FR-4: Content versioning

## Acceptance
- Nội dung đúng và có test.
- UX phù hợp trẻ 5–7 tuổi nếu có tương tác.
- Bảo vệ dữ liệu trẻ em.
