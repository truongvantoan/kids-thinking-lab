# Requirements — Dashboard phụ huynh

## Objective
Tiến độ và năng lực, quyền riêng tư và đồng ý xử lý dữ liệu trẻ.

## Functional requirements
- FR-1: Progress
- FR-2: Insights
- FR-3: Consent
- FR-4: Privacy

## Acceptance
- Nội dung đúng và có test.
- UX phù hợp trẻ 5–7 tuổi nếu có tương tác.
- Bảo vệ dữ liệu trẻ em.
