# Design — Nền tảng ứng dụng

## Approach
Thiết lập Next.js, routing, design tokens, CI/CD, môi trường và cấu trúc dữ liệu.

## Components
- Khởi tạo app và CI
- Thiết kế shell, navigation
- Thiết lập test, logging, accessibility

## Data & interfaces
Ưu tiên module riêng, dữ liệu có schema rõ, các quy tắc nghiệp vụ kiểm thử độc lập UI.

## Risks / open decisions
Cần chốt UX chi tiết, ước lượng và kiến trúc phụ thuộc khi bắt đầu Epic.
