# Requirements — Quản trị nội dung

## Objective
Soạn, kiểm duyệt, xem trước, phát hành và versioning bài học.

## Functional requirements
- FR-1: Authoring
- FR-2: Preview
- FR-3: Review
- FR-4: Publishing

## Acceptance
- Nội dung đúng và có test.
- UX phù hợp trẻ 5–7 tuổi nếu có tương tác.
- Bảo vệ dữ liệu trẻ em.
