# Definition of Done

- Acceptance criteria được kiểm tra.
- UI hỗ trợ mobile và bàn phím ở mức phù hợp.
- Nội dung tiếng Việt đúng, câu hỏi không mơ hồ, đáp án và giải thích nhất quán.
- Unit test cho logic tính cân và validator.
- Không thu thập dữ liệu trẻ em ngoài phạm vi được duyệt.
- CI/build thành công; preview được review.
- Cập nhật docs và backlog tương ứng.
